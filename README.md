# Gibbs Racing Company · Team 12 · ECE 5 Fall 2026

Plain HTML/CSS/JS. Open `index.html` in a browser and it works. No build step.

## Files
- `index.html`: the whole site. Every placeholder has an HTML comment starting with `PLACEHOLDER [Req N: ...]`. Search for `PLACEHOLDER` to find them all.
- `style.css`: styling
- `script.js`: start lights, nav highlighting, pin hover, pin editor
- `assets/gibbs-racing-company-logo.webp`: logo (hero, footer, favicon)
- `images/`: drop your photos and video here

## Filling it in
- Unfinished text has `class="tbd"` (dashed yellow box). Delete the class once the real content is in.
- Photos: replace each `<div class="ph" ...></div>` with the `<img>` line given in the comment above it.
- Car diagram pins: open `index.html?pins`, drag the numbers onto your photo, copy the values from the yellow box into each pin's `style=""`.

## Hosting (free, public link)
- **GitHub Pages:** push this folder to a repo, then Settings → Pages → Deploy from branch → `main` / root.
- **Netlify Drop:** drag the folder onto app.netlify.com/drop.
